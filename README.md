# Meus Dotfiles e Ambiente de Desenvolvimento

Repositorio dedicado ao armazenamento e versionamento das minhas configuracoes pessoais, atalhos de terminal e documentacao de aprendizado continuo em ambiente Linux (foco em Ubuntu/Debian).

## Estrutura do Repositorio

* [Configuracoes do Tmux](./tmux/README.md): Configuracao com tema Dracula, prefixo customizado e persistencia de sessoes.
* [Configuracoes do Neovim](./nvim/README.md): Configuracao em Lua com foco em usabilidade similar ao VS Code e navegacao por mouse.

## Proposito

Este espaco centraliza o backup de configuracoes para novas instalacoes e atua como documentacao tecnica. Cada modulo possui uma secao de aprendizados para registrar a resolucao de problemas e comandos uteis do dia a dia.
